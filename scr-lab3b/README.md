Задание — «Справочник пользователей»
1. Интерфейс и CSS. Создайте страницу с кнопкой «Загрузить пользователей», подписанным полем «Поиск по имени», областью списка пользователей, отдельной областью публикаций и сообщениями о состоянии/ошибках. Оформите страницу с помощью CSS: отступы, цвета,  читаемые карточки и кнопки.
2. Загрузка пользователей (GET). По нажатию кнопки выполните запрос к https://jsonplaceholder.typicode.com/users с помощью fetch и async/await. Проверьте response.ok, прочитайте JSON и выведите имя, email и город каждого пользователя с помощью DOM.
3. Поиск по имени. При вводе текста фильтруйте уже загруженный список без нового HTTP-запроса. Поиск должен игнорировать регистр. Если совпадений нет, покажите сообщение «Пользователи не найдены».
4. Публикации пользователя (GET). Добавьте кнопку «Показать публикации» для каждого пользователя. По нажатию отправьте запрос на https://jsonplaceholder.typicode.com/posts?userId=ID, подставив реальный ID пользователя. Выведите заголовки и тексты первых трёх публикаций в отдельной области.
5. Загрузка и обработка ошибок. Во время каждого запроса показывайте «Загрузка...». На время загрузки отключайте кнопку «Загрузить пользователей», затем включайте её снова.Используйте response.ok и try/catch/finally для обработки HTTP-ошибок и сетевых сбоев; обеспечьте возможность повторной попытки. Технические требования Используйте HTML, CSS и обычный JavaScript без фреймворков. Разместите JavaScript в отдельном файле app.js, CSS - в style.css. Для обработки событий и изменения страницы используйте addEventListener, createElement и textContent. Страница должна обновляться без перезагрузки. localStorage, серверная часть и база данных не требуются.

Проверка перед отправкой
- Нажмите «Загрузить пользователей»: на странице появятся 10 пользователей с именем, email и городом.
- Введите «Leanne»: останутся подходящие записи; введите неизвестное имя: появится сообщение об отсутствии результатов.
- Нажмите «Показать публикации»: появятся заголовки и тексты первых трёх публикаций выбранного пользователя.
- Временно замените /users на /userz (HTTP 404): появится сообщение об ошибке. Верните правильный адрес и убедитесь, что повторный запрос работает.
- Проверьте работоспособность всех элементов и наличие CSS-оформления.
