# Установка Python на Windows 🐍 - - - Язык Python относится к свободному программному обеспечению, поэтому его можно скачать с официального сайта, свободно распространять и устанавливать на все современные операционные системы. ## Шаг 1. Скачайте установщик Python 3 1. Откройте окно браузера и перейдите на сайт [python.org](https://www.python.org/); 2. Кликните по ссылке Downloads; 3. Кликните по желтой кнопке Download Python 3.x. ⚠️ Версия Python может отличаться. На данный момент рекомендуемой версией является Python 3.14.0. ## Шаг 2. Запустите установщик 1. Установите галочку напротив Add Python 3.x to PATH; 2. Кликните Install Now; 3. Через несколько минут на вашем компьютере будет установлен Python 🐍
